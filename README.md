# 고고! 이설 공주의 미션 대작전 💗

매일의 공부 미션을 체크하고 **하트 도장**을 모으는 어린이 칭찬 스티커판입니다.
핑크·파스텔 공주 테마, 하트 모양 도장, 30칸 스티커판.

- 파일: `index.html` 하나로 동작합니다 (CSS·JS 모두 안에 들어 있음)
- 폰 세로 화면(390×844) 기준으로 만들었고, 320px 폭에서도 가로 스크롤이 없습니다
- 기록은 **이 기기 브라우저의 localStorage** 에만 저장됩니다. 서버로 보내는 코드가 없습니다

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 요일 자동 선택 | 화면을 열면 오늘 요일 미션이 바로 보입니다 |
| 요일 미리보기 | 월~일 탭으로 다른 요일 미션을 읽기 전용(체크 잠금)으로 볼 수 있습니다 |
| 다단계 미션 | `원서 3권`처럼 1·2·3 단계를 하나씩 체크할 수 있습니다 (단계 수 설정 가능) |
| 하트 도장 | 오늘 미션을 **모두** 끝내야 도장 1개, 하루에 **한 번**만 |
| 스티커판 | 하트 30칸. 도장마다 날짜(예: `11/16`)가 함께 찍힙니다 |
| 보상 | 30개를 모으면 보상(기본: 아이스크림)을 받고 새 판을 시작합니다 |
| 엄마 설정 | 한 자리 덧셈 문제를 풀어야 열립니다 — 요일별 미션 편집·추가·삭제, 단계 수, 스티커 +1/−1, 보상 변경, 전체 초기화, 백업/복원(JSON 복사·파일) |

## 배포 (GitHub Pages)

`index.html` 이 저장소 루트에 있으면 그대로 Pages 주소에서 열립니다.

```bash
# 저장소를 만들고 올리기 (예: 저장소 이름 heart-mission-board)
git init -b main
git add index.html README.md
git commit -m "고고! 이설 공주의 미션 대작전"
gh repo create heart-mission-board --public --source=. --remote=origin --push

# Pages 켜기 (main 브랜치 루트)
gh api -X POST repos/{owner}/heart-mission-board/pages \
  -f "source[branch]=main" -f "source[path]=/"
```

주소는 `https://<사용자>.github.io/heart-mission-board/` 형태가 됩니다.
Settings → Pages 화면에서 직접 켜도 됩니다.

## 백업

폰을 바꾸거나 브라우저 기록을 지우면 스티커판도 사라집니다.
`엄마 설정 → 백업 / 복원`에서 **복사**하거나 **파일로 저장**해 두세요.
새 기기에서 같은 화면에 붙여넣고 **붙여넣기 복원**을 누르면 그대로 돌아옵니다.

## 참고

- 인터넷이 없어도 열립니다(글꼴만 온라인에서 불러오고, 없으면 기본 글꼴로 보입니다).
- 검색엔진에 노출되지 않도록 `noindex` 를 넣어 두었습니다.
